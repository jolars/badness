\begin{itemize}
  \item[\char`^ \textrm{or} \\A]
    Start of the subject token list.
  \item[\char`$\textrm{,} \\Z \textrm{or} \\z]
    End of the subject token list.
\end{itemize}

A close-group character is written \char`} and an open-group
character \char`{ in running text, while the escaped forms
\catcode`\%=12 and \catcode`\^^A=14 keep their ordinary shape.
