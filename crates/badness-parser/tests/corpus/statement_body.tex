% Statement recognition in curated statementBody bodies (the TikZ/pgf picture
% family): each run up to a top-level `;` wraps in a STATEMENT node; a run that
% never reaches one stays plain paragraph content.
\documentclass{article}
\usepackage{tikz, pgfplots}
\begin{document}

\begin{tikzpicture}[scale=1.2]
  \draw (0,0) -- (1,1);
  \node[fill=red] at (0,0) {A};
  \draw[thick] (2,2) circle (1);
  % a bound comment run lands inside the statement after it
  \node at (1,1) {B};
  \tikzset{every node/.style={circle}}
  \foreach \x in {0,1,2}
    \draw (\x,0) -- (\x,1);
  \begin{scope}[shift={(3,0)}]
    \draw (0,0) rectangle (1,1);
  \end{scope}
  \node at (4,4)
    {\begin{itemize}
        \item a semicolon here; does not terminate
      \end{itemize}
    };
  \node[label={a;b}] at (5,5) {$u;v$};
\end{tikzpicture}

A paragraph of ordinary prose between pictures; its semicolon is plain text.
